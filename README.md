📚 Library App
This is a JavaScript-based book tracking application developed as part of the The Odin Project curriculum. 
It allows users to add, view, categorize, and manage their personal book collection directly in the browser.
The app was built using HTML, CSS, and vanilla JavaScript, with a focus on DOM manipulation and object-oriented programming.

https://iamangina.github.io/Library-OdinProject/

📚 Features
-Add a Book: Users can add a book by entering its title, author, number of pages, and current reading status.

-Reading Status Categories

-Book Cards:

Each book is displayed as a styled card on a virtual shelf.
Cards show the book’s title, author, and page count.

-Edit Reading Status: Each book includes an "Edit" button to update its status.

-Delete Book: Each card has a "Delete" button that removes it from the shelf.

-Modal Form: A clean overlay form appears for adding new books, ensuring an intuitive and focused experience.
